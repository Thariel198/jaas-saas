Contrato de formato — vista_estado_cuenta

Sub-contexto: libro_mayor/estado_cuenta (carpeta vista/)  |  Tipo: Vista operacional — proyección regenerable, no auditoría  |  Consumidor: mesa (PDF imprimible) · agente (tool estado_cuenta.py)  |  Versión: 1.0  |  12/07/2026

Propósito

Responde en una pantalla: "¿cuánto debe este predio, de qué, y a dónde fue lo que ya pagó?"

  • Se regenera on-demand desde store de CARGOS + store de APLICACIONES — nunca se edita a mano.
  • Si la lógica de presentación cambia mañana, esta vista se regenera; los stores de auditoría no cambian.
  • Formato dual: hoja Excel (para exportar/filtrar) y PDF de una página (para la mesa, imprimible).
No es la fuente de verdad. Si esta vista y los stores de CARGO/APLICACIÓN alguna vez no cuadran, el store manda — se regenera la vista, nunca al revés.

Reglas de presentación

  • ESTADO por cargo: CUBIERTO si APLICADO = MONTO; ABIERTO si APLICADO < MONTO (parcial o cero).
  • Cargos ordenados por prioridad (CONSUMO → CORTE → CONVENIO → ACUERDOS → MULTA → OTROS, tramo pueblo corregido 2026-07-23), no por fecha.
  • Si el predio tiene SALDO_A_FAVOR vigente, se muestra como fila especial al final, fondo morado.
  • SALDO PENDIENTE = Σ(MONTO − APLICADO) de cargos abiertos — siempre derivado, nunca una celda editable.
