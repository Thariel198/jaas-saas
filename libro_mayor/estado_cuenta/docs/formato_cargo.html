Propósito

El HECHO de que nació una obligación — sin decir todavía cómo se cubrió.

  • 1 fila = 1 cargo: un predio debe X soles por un concepto en un mes concreto.
  • Cualquier fuente puede emitir (SOURCE identifica quién) — el motor las trata igual.
  • Un cargo queda "abierto" hasta que las aplicaciones cubren su MONTO completo.
  • Nunca se edita. Una corrección de monto es un AJUSTE aparte (ver cuenta_repo.registrar_ajuste).
Decisión ⑧: toda deuda de un predio es un CARGO acá, venga de donde venga — ya no hay deuda invisible tipo PREDIOS_INSTALACION_EXCLUIDOS.

CARGO_ID — determinista siempre

CARGO_ID = sha256[:8](JASS_ID, MZ, LT, CONCEPTO, SUB_CONCEPTO, MES_CARGO) — determinista siempre, sin identidad condicional (misma regla que ABONO_ID). SUB_CONCEPTO vacío entra a la clave como cadena vacía. Re-sembrar el mismo cargo mapea al mismo id → import idempotente, no duplica.
