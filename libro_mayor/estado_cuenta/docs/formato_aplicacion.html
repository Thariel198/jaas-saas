Propósito

La INTERPRETACIÓN: a qué cargo fue cada porción de cada abono.

  • 1 fila = 1 imputación: parte (o todo) un abono cubre un cargo concreto.
  • Un abono grande puede generar varias filas (una por cada cargo que cubre, en orden de prioridad).
  • Solo el motor de aplicación escribe acá — ningún feeder (2_planilla, 5_cobranza) aplica directo.
  • Referencia, nunca recopia: ABONO_ID apunta a caja, CARGO apunta al cargo — el monto vive una sola vez en cada lado.
Fila especial SALDO_A_FAVOR: cuando un abono supera todos los cargos abiertos, el sobrante se aplica a este concepto explícito (crédito del predio) — no queda "flotando" sin fila.

Invariante de conservación (verificado por auditoria_conservacion())

Por cada (JASS_ID, ABONO_ID): MONTO(abono) = Σ MONTO_APLICADO a conceptos + SALDO_A_FAVOR generado
Global por JASS_ID: Σ abonos = Σ aplicado + Σ saldo_a_favor_vigente + Σ devoluciones
