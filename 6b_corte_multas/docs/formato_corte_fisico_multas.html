Propósito

¿A quién va el operario a cortar el servicio por deuda de multas?
Usuarios que no saldaron toda su deuda (agua + multa + acuerdos) durante la ventana de gracia.

  • Regla: pagado_total < cargo_agua + MULTA + ACUERDOS_ASAMBLEA → ESTADO = CORTADO.
  • PENALIDAD_FINAL = S/40 — valor fijo para todos los cortados.
  • ARRASTRE_MULTA = max(0, 40 − PAGADO_PENALIDAD_MULTA) — lo que queda del cargo de penalidad.
  • El operario usa MZ y LT como dirección de campo para localizar la conexión.
  • La deuda de consumo (CARGO_AGUA no cubierta) la gestiona 5_cobranza — no se duplica aquí.
Condición más estricta que 6_corte: en 6_corte basta pagar S/20 para salvarse. Aquí se requiere saldar toda la deuda (agua + multa + acuerdos). Si pagó S/20 de penalidad pero le quedó deuda de consumo sin cubrir, igual va a corte físico.
