Propósito

Datos del ciclo de facturación que no existen en planilla_2026-07.xlsx (2_planilla no los conoce: son de emisión de boleta, no de cálculo de deuda) pero que enriquecimiento/main.py necesita para completar cada fila de DATA_boletas.xlsx: fechas del recibo, rango de lectura, datos de cobro presencial/Yape, y el número de recibo inicial del mes.

No se regenera solo. Correr crear_config.py únicamente si el archivo no existe (primera vez o se borró). Si ya existe de un mes anterior, abrirlo directo y actualizar los valores — volver a correr el template pisaría los datos ya cargados.

Reglas de lectura (main.py / _cargar_config())

Regla Detalle
Todas las columnas son obligatorias _validar_inputs() aborta con ValueError listando las que falten si el header no trae las 10 columnas exactas (mayúsculas, sin espacios extra).
Siempre lee df.iloc[2] (fila 4 en Excel) Las filas 2 y 3 (descripción/ejemplo) quedan como guía permanente — _validar_inputs() exige al menos 3 filas de datos y que PERIODO en la fila 4 no esté vacío, para no confundir el ejemplo con datos reales.
NUMERO_RECIBO_INICIO se castea a int Vía _float() primero — acepta texto con coma decimal, pero el valor final siempre es entero.
FECHA_PAGO + HORA_PAGO + LUGAR_PAGO + TELEFONO Se combinan en un solo string por _fecha_pago_str(): "PAGO PRESENCIAL: {FECHA_PAGO} de {HORA_PAGO} ({LUGAR_PAGO}), PAGO YAPE: {TELEFONO}" — va literal a la columna fecha pago de DATA_boletas.xlsx.

Invariantes del archivo

Invariante Garantía
Un valor por ciclo, no histórico El archivo no acumula filas — cada corrida de main.py aplica los mismos 10 valores a todas las filas de DATA_boletas.xlsx de ese ciclo.
No trackeado como dato permanente A diferencia de seguimiento_pueblo o trazabilidad_*, este archivo no es un ledger — es un formulario de una sola fila que se reescribe cada mes.

Señales de alerta

Señal Interpretación
PERIODO con el mes equivocado Se copió el archivo de un mes anterior sin actualizar — revisar las 10 columnas, no solo la que se sabe que cambió.
NUMERO_RECIBO_INICIO se solapa con el rango del mes anterior Boletas duplicadas con el mismo número de recibo — confirmar el último recibo emitido antes de fijar el inicio de este ciclo.
