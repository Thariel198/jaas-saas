estado_ciclo.json — ubicado en shared/reporte_acumulado_procesado/.
Registro persistente del estado del ciclo mensual JASS. Cada módulo lo lee antes de correr y escribe solo los campos que le corresponden. Un agente puede leer este archivo para saber en qué fase está el pipeline sin abrir ningún Excel.
Patrón: Saga State — el ciclo es un proceso de negocio de larga duración que sobrevive reinicios.
Estructura del archivo
{
  "2026-07": {
    "estado": "ABIERTO", ← 5_cobranza escribe al iniciar el ciclo 5_cobranza
    "ultima_actualizacion": "2026-07-01T08:00:00",
    "arrastre": {
      "generado": false, 5_cobranza ← true al escribir arrastre_consolidado
      "generado_en": null,
      "validado": false, 5b_validacion ← true si planilla_cobrado pasa todas las validaciones
      "validado_en": null
    }
  }
}
Writers por campo
Campo Quién escribe Cuándo Qué significa
estado 5_cobranza Al abrir el ciclo ABIERTO → ciclo en curso
arrastre.generado 5_cobranza Al escribir arrastre_consolidado El arrastre existe pero aún no fue validado
arrastre.generado_en 5_cobranza Junto con generado:true Timestamp ISO para trazabilidad
arrastre.validado 5b_validacion Si pasa todas las validaciones El arrastre es oficial — 2_planilla puede usarlo
arrastre.validado_en 5b_validacion Junto con validado:true Timestamp ISO para trazabilidad
ultima_actualizacion Cualquier módulo Cada vez que escribe Último módulo que tocó el archivo
Máquina de estados del ciclo
ABIERTO
5_cobranza inicia
arrastre.generado: false
→
ABIERTO
5_cobranza genera arrastre
arrastre.generado: true
→
ABIERTO
5b_validacion aprueba
arrastre.validado: true
→
CERRADO
7_cierre genera reporte
estado: CERRADO
Gate en 2_planilla: antes de correr, lee estado_ciclo[ciclo_anterior]["arrastre"]["validado"]. Si es false o la clave no existe → error explícito, no continúa.
Gate en 5_cobranza (generar arrastre): solo corre si arrastre.generado es false — idempotencia garantizada.
