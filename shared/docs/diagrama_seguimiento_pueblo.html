seguimiento_pueblo — arquitectura event-sourced

Deuda de multa · acuerdos de asamblea · convenio — lote (MZ, LT) como llave, saldo derivado nunca guardado

Por qué event-sourced: "génesis" (foto inicial), "cargo nuevo" (multa de julio) y "pago" (5_cobranza) son la misma cosa vista desde tres momentos: un evento. Guardar eventos en vez de un saldo mutable significa que el saldo de cualquier mes se puede reconstruir siempre, nadie edita una celda a mano, y cada movimiento queda auditado con quién y por qué — la forma que un agente puede invocar sin leer código.

3
shared/seguimiento_repo.py
único writer · cada función es una tool que un agente invoca sin leer código
API pública
registrar_cargo(...) / registrar_pago(...)
Append de evento. Idempotente por (source, audit_ref) — reintentar no duplica.
registrar_ajuste(...)
Corrección — nueva fila con motivo obligatorio, nunca reescribe una fila previa.
get_saldo(mz, lt, concepto, mes) → float
Suma eventos hasta ese mes. Esto es lo que 2_planilla consulta.
estado_cuenta(mz, lt, concepto) → DataFrame
Pivot a la vista ancha (DEUDA·PAGO·SALDO por mes) — para que la lea un humano.

4
Estado derivado
nunca se guarda directamente — siempre se calcula desde los eventos
SALDO(mz, lt, concepto, mes) = Σ cargos − Σ pagos ± Σ ajustes (hasta ese mes)
Si el saldo estuviera guardado como celda mutable, dos escrituras concurrentes se pisan (el mismo bug que B7 en shared/planilla_mes). Al derivarlo de eventos, no hay celda que pisar.

Single writer El registro solo se escribe vía seguimiento_repo.py. El cierre mensual usa un append batch atómico; las corridas provisionales no escriben eventos.
Append-only real Un evento nunca se modifica ni se borra. Una corrección es un nuevo evento de tipo ajuste con motivo.
Guardar largo, mostrar ancho El registro (fuente) es una tabla larga con schema fijo. El estado de cuenta ancho es un pivot regenerable — nunca se edita directo.
Listo para escalar Cuando el registro migre a Postgres, solo el repo cambia. 5_cobranza y 2_planilla siguen llamando la misma API.
