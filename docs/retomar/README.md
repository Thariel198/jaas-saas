# Indice de RETOMAR

```text
docs/retomar/
├── README.md                         indice unico
├── RETOMAR_auditoria_..._2026-08-24 estado operativo vigente
└── RETOMAR_*.md                      historial por fecha y tema
```

Todos los handoffs `RETOMAR` del repositorio se guardan en esta carpeta. Un
documento conserva contexto historico, pero no reemplaza decisiones cerradas en
`docs/decisiones/estado_decisiones.md` ni eventos activos de `LEER_ANTES.md`.

- [`RETOMAR_EJECUTAR_5_FORCE_2026-08-23.md`](RETOMAR_EJECUTAR_5_FORCE_2026-08-23.md): estado previo del cierre de agosto; queda como evidencia historica y no autoriza repetir `--force` sobre julio.

## Archivo historico

Los nombres incluyen fecha cuando estaba disponible. Para buscar por predio,
concepto o decision, usar busqueda de texto dentro de `docs/retomar/`; no asumir
que el documento mas reciente invalida por si solo uno anterior.
